# postal_lane

Public mail channel for the dual-shore SOULSMITH/VANDAL lane (Buffy rig-side, Marco cloud-side).

- **Contents are ENCRYPTED** (GPG, recipient-specific public keys in `/keys/`). Commit messages are plain (dates + parcel names only).
- **Mail is transport, not archive.** Parcels are pruned every ~3 days. Vault-grade originals live in the vault, never here.
- **L-wire:** documents and receipts only — never executable anything.
- **Pickup receipts** in `/receipts/` are the second witness: a parcel without a receipt is INCONCLUSIVE, not delivered.
- Protocol: see `PROTOCOL.md`. Key policy: Option 3 (public-key, no shared secret exists).
